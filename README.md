# نقشه لحظه‌ای قطعی برق قائم‌شهر

سامانه محلی که وضعیت قطعی/وصل بودن مناطق قائم‌شهر را روی نقشه نشان می‌دهد،
با ساعت تغییر می‌کند و با اسلایدر زمان می‌توان وضعیت هر لحظه از امروز/فردا را دید.

**منبع داده:** سامانه رسمی اطلاع‌رسانی خاموشی شرکت توزیع نیروی برق مازندران
(khamooshi.maztozi.ir) — هر ۵ دقیقه poll می‌شود.

## اجرا

```
start.bat
```
سپس در مرورگر: http://127.0.0.1:8765

(بدون نیاز به نصب هیچ پکیجی؛ فقط `jdatetime` یک‌بار نصب شده است)

## امکانات

- **نقشه زنده:** پلی‌گون هر فیدر رنگی است — قرمز = قطع، سبز = وصل، نارنجی = خاموشی تا ۲ ساعت دیگر
- **اسلایدر زمان:** بکشید تا وضعیت هر لحظه از امروز/فردا را ببینید؛ دکمه ▶ پخش خودکار
- **پنل جزئیات:** کلیک روی هر منطقه — برنامه امروز/فردا، گزارش‌های زنده، محله‌ها
- **خانه من:** دکمه «🏠 خانه من» به فیدر 402 (ترک‌محله، مسکن مهر) می‌رود
- **به‌روزرسانی خودکار:** هر ۶۰ ثانیه وضعیت زنده؛ poll سرور هر ۵ دقیقه

## رنگ‌ها

| رنگ | معنی |
|---|---|
| قرمز روشن | قطع برنامه‌ریزی‌شده (ساعت اعلامی + ۲ ساعت) |
| قرمز تیره | قطع گزارش‌شده زنده (ثبت اکیپ/مشترک) |
| نارنجی | خاموشی برنامه‌ریزی‌شده در ۲ ساعت آینده |
| سبز | وصل |
| خاکستری | آینده / بدون برنامه |

## ساختار

```
server.py           سرور + poll هر ۵ دقیقه
fetch_poll.py       poll مستقل (اجرای دستی: python fetch_poll.py)
status_model.py     منطق محاسبه وضعیت (تست: python status_model.py --selftest)
build_zones.py      ساخت پلی‌گون‌ها (python build_zones.py)
jalali.py           تبدیل تاریخ شمسی
data/history.jsonl  اسنپ‌شات‌های هر poll
data/zones.json     پلی‌گون فیدرها (قابل ویرایش دستی)
web/index.html      نقشه
```

## محدودیت‌ها (مهم — صادقانه)

1. **مرزها تقریبی‌اند.** API رسمی مختصات نمی‌دهد؛ پلی‌گون‌ها از روی متن آدرس فیدرها
   و جغرافیای شهر تخمین زده شده‌اند. برای اصلاح، مختصات `polygon` را در
   `data/zones.json` ویرایش کنید و سرور را ری‌استارت کنید.
2. **«قطع/وصل لحظه‌ای» تخمین از داده رسمی است، نه سنسور.** دو منبع دارد:
   - پنجره برنامه‌ریزی‌شده (ساعت اعلامی + ۲ ساعت)
   - گزارش‌های زنده بی‌برنامه که تا وقتی در لیست سامانه باشند قطع محسوب می‌شوند
3. **گزارش‌های زنده بدون کد فیدر** (مثل «ثبت شده در صندوق صوتی») در آمار «نامشخص» دیده نمی‌شوند؛
   سامانه رسمی گاهی خاموشی واقعی را با تأخیر ثبت می‌کند.
4. تایل نقشه OSM از ایران کند است (اولین تایل ~۳ ثانیه) — طبیعی است.
5. برای کار ریل‌تایم، سرور باید روشن باشد (start.bat).

## فیدرهای قائم‌شهر

۴۷ فیدر برنامه‌ریزی‌شده (امور برق مرکزی قائم‌شهر = area 31) — ناحیه ۲ (32) و
شبکه دو (34) نیز poll می‌شوند ولی فعلاً برنامه‌ای ندارند. کد فیدر در ابتدای آدرس
(مثل `402- خیابان ساری...`) مشخص است؛ همان کد روی نقشه است.
